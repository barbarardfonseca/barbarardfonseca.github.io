Análise de Histórico Meteorológico

Este dashboard apresenta uma análise detalhada dos dados climáticos históricos do Brasil, abrangendo o período de 2016 a 2026. O objetivo é identificar padrões de aquecimento global, sazonalidade e variações regionais de temperatura.

Funcionalidades:
  • Filtros dinâmicos por Estado, Cidade e Período.
  • Indicadores de temperatura média, máxima e mínima.
  • Gráficos interativos de tendência e evolução temporal.

Recursos Utilizados: Python
